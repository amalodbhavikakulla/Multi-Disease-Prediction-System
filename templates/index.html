ABOUT THE PROJECT

AI for Preliminary Health Risk Assessment

This project demonstrates how Data Science and Machine Learning can be applied to healthcare datasets to develop a multi-disease prediction application.

The system provides preliminary risk predictions for Diabetes, Heart Disease, and Liver Disease based on user-provided health parameters.

Python Machine Learning Scikit-learn Pandas NumPy Flask
